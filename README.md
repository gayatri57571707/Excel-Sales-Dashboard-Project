# Excel Sales Dashboard

An interactive Sales Dashboard created using Microsoft Excel to analyze business sales performance.

## Project Overview

This dashboard provides insights into:

* Total Sales
* Profit
* COGS
* Product Performance
* Regional Sales
* Sales Trends

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Excel Formulas
